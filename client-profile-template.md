# Client profile template

Optional. Copy this into the bottom of SKILL.md (or keep it as a separate file per client) so Claude knows each client's quirks. Delete any line that doesn't apply.

## [Client name]

- **Contacts:** who writes briefs, who designs, who signs off ads.
- **Briefs and copy:** where they live (Drive folder, Notion page, email) and what they're usually called.
- **Creative files:** folder structure (e.g. one folder per concept, subfolders per language or size).
- **Campaign structure:** campaigns and ad sets, and the usual build order.
- **Objective:** e.g. Leads with Instant forms only, or Sales with a purchase event. Note anything that forces a rebuild if wrong.
- **Special ad category:** if any, and what it restricts.
- **Budget:** monthly Meta budget and how it's split.
- **House style:** spelling, formatting or wording rules the client cares about.
- **Notes and change logs:** where follow-up notes and change logs should go.
